电商系统部署与使用手册

一、数据库部署

本系统采用 MySQL 8.0 作为关系型数据库，负责存储用户、商品、订单、店铺等核心业务数据。

1. 数据库环境要求

数据库类型: MySQL 8.0 及以上版本
字符集: utf8mb4
排序规则: utf8mb4_unicode_ci
默认端口: 3306

2. 数据库安装步骤

步骤一: 下载并安装 MySQL 8.0

访问 MySQL 官网 https://dev.mysql.com/downloads/mysql/ 下载对应操作系统的安装包。Windows 系统推荐下载 MSI 安装程序，按照安装向导完成安装。安装过程中需设置 root 用户密码，请妥善保管。

步骤二: 启动 MySQL 服务

Windows 系统:
打开命令提示符（以管理员身份运行），执行以下命令:
net start MySQL80

Linux 系统:
sudo systemctl start mysqld

步骤三: 登录 MySQL 并创建数据库

打开命令行工具，执行:
mysql -u root -p

输入安装时设置的 root 密码后，在 MySQL 命令行中执行以下 SQL 语句创建数据库:
CREATE DATABASE web CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

3. 数据库导入

步骤一: 准备 SQL 脚本文件

将项目中的数据库脚本文件 backend/db/web.sql 复制到服务器或部署环境中。该脚本包含了系统所需的全部表结构和初始数据。

步骤二: 导入数据库

方式一（命令行导入）:
mysql -u root -p web < backend/db/web.sql

方式二（MySQL 命令行导入）:
登录 MySQL 后执行:
USE web;
SOURCE /path/to/backend/db/web.sql;

4. 数据库配置

编辑后端配置文件 backend/config/index.js，修改数据库连接参数:

database: {
  host: 'localhost',      // 数据库主机地址，远程数据库填写服务器IP
  user: 'root',           // 数据库用户名
  password: 'root',       // 数据库密码，根据实际安装时设置的密码修改
  database: 'web',        // 数据库名称
  port: 3306,             // 数据库端口号
  charset: 'utf8mb4'      // 字符集
}

5. 数据库验证

导入完成后，执行以下命令验证数据库是否正确导入:
mysql -u root -p web -e "SHOW TABLES;"

系统应包含以下主要数据表:
- users（用户表）: 存储用户基本信息、登录凭证、角色等
- roles（角色表）: 存储系统角色及权限配置
- products（商品表）: 存储商品信息、价格、库存等
- orders（订单表）: 存储订单信息及状态
- order_items（订单明细表）: 存储订单商品明细
- shops（店铺表）: 存储店铺信息
- categories（分类表）: 存储商品分类
- coupons（优惠券表）: 存储优惠券信息
- addresses（地址表）: 存储用户收货地址
- cart_items（购物车表）: 存储用户购物车商品
- after_sales（售后表）: 存储售后申请信息
- conversations（会话表）: 存储客服会话
- messages（消息表）: 存储聊天消息
- reviews（评价表）: 存储商品评价
- audit_logs（审计日志表）: 记录系统操作日志

6. 数据库备份与恢复

备份命令:
mysqldump -u root -p web > web_backup.sql

恢复命令:
mysql -u root -p web < web_backup.sql

二、系统部署

本系统采用前后端分离架构，后端基于 Node.js + Express 框架，前端基于 Vue.js + Element Plus 构建。系统不依赖 Tomcat，使用 Node.js 作为 Web 应用服务器。

1. Tomcat或其他Web应用服务器的配置

1.1 运行环境要求

Node.js: 18.0 及以上版本
npm: 9.0 及以上版本
MySQL: 8.0 及以上版本
Redis: 6.0 及以上版本（可选，用于缓存）

1.2 Node.js 安装

访问 Node.js 官网 https://nodejs.org/ 下载 LTS（长期支持）版本安装包。Windows 系统下载 .msi 安装包，双击安装即可，安装过程中勾选"Add to PATH"选项。

安装完成后，打开命令提示符验证安装:
node -v
npm -v

应显示对应的版本号。

1.3 Redis 安装（可选）

Redis 用于系统缓存，可提升系统性能。如不需要缓存功能，可在配置文件中关闭。

Windows 系统:
可从 https://github.com/tporadowski/redis/releases 下载 Windows 版本 Redis。

Linux 系统:
sudo apt-get install redis-server
sudo systemctl start redis-server

验证 Redis 是否启动:
redis-cli ping
应返回 PONG。

1.4 后端服务配置

进入后端项目目录:
cd backend

安装项目依赖:
npm install

该命令将自动安装以下核心依赖:
- express: Web 应用框架
- mysql2: MySQL 数据库驱动
- jsonwebtoken: JWT 身份认证
- bcryptjs: 密码加密
- socket.io: 实时通信（客服聊天功能）
- cors: 跨域资源共享
- sharp: 图片处理
- winston: 日志管理
- ioredis: Redis 客户端

编辑配置文件 backend/config/index.js，确认以下配置项:

module.exports = {
  database: {
    host: 'localhost',
    user: 'root',
    password: 'root',
    database: 'web',
    port: 3306,
    charset: 'utf8mb4'
  },
  server: {
    port: 3000
  },
  jwtSecret: 'bigsize_ecommerce_jwt_secret_key_2026_secure_token_signing',
  redis: {
    enabled: true,
    host: '127.0.0.1',
    port: 6379,
    password: '',
    db: 0,
    keyPrefix: 'backend:'
  }
}

1.5 前端服务配置

进入前端项目目录:
cd frontend

安装项目依赖:
npm install

该命令将自动安装以下核心依赖:
- vue: 前端框架
- element-plus: UI 组件库
- vite: 前端构建工具
- vue-router: 路由管理
- pinia: 状态管理
- axios: HTTP 请求库

编辑配置文件 frontend/vite.config.js，确认 API 代理配置:

export default defineConfig({
  server: {
    port: 5173,
    strictPort: true,
    proxy: {
      '/api': {
        target: 'http://localhost:3000',
        changeOrigin: true,
        secure: false
      }
    }
  }
})

2. 详细描述本系统如何部署到Tomcat或其它Web应用服务器中

2.1 开发环境部署

步骤一: 启动后端服务

进入后端目录并启动:
cd backend
npm run dev

或直接执行:
node index.js

启动成功后，终端将显示以下信息:
初始化数据库表...
数据库表初始化完成
服务器启动成功，端口: 3000
Socket.io服务器已启动

后端服务将在 http://localhost:3000 启动，提供 RESTful API 接口和 Socket.io 实时通信服务。

步骤二: 验证后端服务

打开浏览器访问:
http://localhost:3000/api/health

应返回 JSON 响应:
{
  "status": "ok",
  "message": "服务器运行正常"
}

步骤三: 启动前端服务

进入前端目录并启动:
cd frontend
npm run dev

启动成功后，终端将显示:
VITE v5.x.x  ready in xxx ms
Local:   http://localhost:5173/
Network: use --host to expose

前端开发服务器将在 http://localhost:5173 启动，自动代理 /api 请求到后端服务。

2.2 生产环境部署

步骤一: 前端项目构建

进入前端目录执行构建:
cd frontend
npm run build

构建完成后，产物将生成在 frontend/dist 目录中，包含所有静态资源文件（HTML、CSS、JavaScript、图片等）。

步骤二: 配置 Nginx 静态文件服务器

安装 Nginx 后，编辑配置文件（通常位于 /etc/nginx/nginx.conf 或 /etc/nginx/conf.d/default.conf）:

server {
    listen 80;
    server_name your-domain.com;

    # 前端静态文件
    location / {
        root /path/to/frontend/dist;
        index index.html;
        try_files $uri $uri/ /index.html;
    }

    # 后端 API 代理
    location /api {
        proxy_pass http://localhost:3000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_cache_bypass $http_upgrade;
    }

    # Socket.io 实时通信
    location /socket.io {
        proxy_pass http://localhost:3000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_set_header Host $host;
    }
}

重启 Nginx 使配置生效:
sudo systemctl restart nginx

步骤三: 后端进程守护（PM2）

安装 PM2 进程管理器:
npm install -g pm2

进入后端目录启动服务:
cd backend
pm2 start index.js --name ecommerce-backend

保存进程列表:
pm2 save

设置开机自启动:
pm2 startup

5. 给出本系统的使用手册

5.1 系统功能概述

本系统是一个多角色电商平台，支持管理员、运营人员、客服人员、商家、买家五种角色，包含以下核心功能模块:

商品管理: 商品发布、编辑、上下架、分类管理、热销商品、新品推荐
订单管理: 订单查看、发货、退款、物流跟踪、订单关闭
用户管理: 用户列表、角色管理、权限分配、账号禁用/启用
店铺管理: 店铺信息设置、实名认证、店铺审核
营销管理: 优惠券创建与发放、热销商品设置、新品推荐
售后管理: 退货退款申请、售后审核、物流跟踪
消息系统: 实时客服聊天、内部消息通知
数据统计: 销售统计、用户分析、订单报表
评价管理: 商品评价审核、评价删除
讨论区管理: 用户讨论审核、违规内容处理

5.2 管理员操作指南

5.2.1 登录系统

打开浏览器访问 http://localhost:5173
在登录页面输入用户名 admin，密码 admin123
点击"登录"按钮进入管理后台

5.2.2 仪表盘

登录后默认进入仪表盘页面，显示以下信息:
- 销售数据统计: 今日销售额、订单数量、用户增长等
- 订单趋势图表: 近期订单数量变化趋势
- 用户增长情况: 新增用户统计
- 商品销售排行: 热销商品 TOP 列表

5.2.3 商品管理

点击左侧菜单"商品管理"进入商品管理页面。

查看商品列表: 浏览系统中所有商品，支持按名称、分类、状态筛选
添加商品: 点击"新增"按钮，填写商品名称、价格、库存、描述、上传图片等信息
编辑商品: 点击商品行的"编辑"按钮，修改商品信息
上下架: 修改商品状态为"上架"或"下架"，下架商品前端不可见
删除商品: 点击"删除"按钮移除商品（谨慎操作）

5.2.4 订单管理

点击左侧菜单"订单管理"进入订单管理页面。

查看订单列表: 浏览所有订单，支持按状态、时间筛选
查看订单详情: 点击订单号查看订单详细信息，包括商品明细、收货地址、支付信息等
发货: 对"待发货"订单填写物流公司和物流单号，确认发货
退款处理: 审核用户的退款申请，同意或拒绝
关闭订单: 对超时未支付或异常订单进行关闭操作

5.2.5 用户管理

点击左侧菜单"用户管理"进入用户管理页面。

查看用户列表: 浏览所有注册用户，支持按用户名、手机号、角色筛选
编辑用户: 修改用户基本信息，如姓名、手机号、邮箱、角色等
禁用/启用用户: 修改用户状态，禁用后用户无法登录
删除用户: 删除违规用户账号（谨慎操作）

5.2.6 角色与权限管理

点击左侧菜单"角色管理"进入角色权限管理页面。

查看角色列表: 浏览系统中所有角色及其权限配置
创建角色: 点击"新增"按钮，填写角色名称和描述
编辑角色: 修改角色名称和描述信息
分配权限: 为角色勾选或取消具体权限，权限包括:
  - dashboard:view（仪表盘查看）
  - product:view/edit/delete/create（商品管理）
  - category:manage（分类管理）
  - order:view/edit/ship/refund/close（订单管理）
  - user:view/edit/delete/create（用户管理）
  - role:view/edit/delete/create（角色管理）
  - shop:view/edit/delete（店铺管理）
  - coupon:manage（优惠券管理）
  - review:manage（评价管理）
  - statistics:view（数据统计）
删除角色: 删除不需要的角色（确保无用户使用该角色）

5.2.7 分类管理

点击左侧菜单"分类管理"进入分类管理页面。

查看分类: 浏览商品分类树形结构
添加分类: 点击"新增"按钮，填写分类名称、排序、图标等
编辑分类: 修改分类信息
删除分类: 删除空分类（分类下无商品时才可删除）

5.2.8 优惠券管理

点击左侧菜单"优惠券管理"进入优惠券管理页面。

创建优惠券: 设置优惠券名称、面额、使用条件（满减金额）、有效期、发放数量

5.5 常见问题

问题一: 后端服务启动失败

解决方法:
- 检查 MySQL 服务是否正常运行
- 检查 backend/config/index.js 中的数据库配置是否正确（主机、用户名、密码、数据库名）
- 检查端口 3000 是否被其他程序占用
- 查看终端错误日志，根据具体错误信息排查

问题二: 前端页面无法访问

解决方法:
- 检查 Node.js 版本是否 >= 18.0（执行 node -v 查看）
- 检查 npm install 是否成功执行，node_modules 目录是否存在
- 检查端口 5173 是否被其他程序占用
- 检查 frontend/vite.config.js 中的 API 代理配置是否正确

问题三: 登录失败

解决方法:
- 确认用户名和密码输入正确
- 管理员账号: admin，密码: admin123
- 检查用户账号状态是否为"启用"
- 执行 npm run fix-admin-account 重置管理员账号
- 清除浏览器缓存后重试

问题四: 图片上传失败

解决方法:
- 检查 backend/uploads 目录是否存在
- 检查 uploads 目录是否有写入权限
- 检查 sharp 依赖是否正确安装（执行 npm install sharp）
- 检查上传的图片格式是否支持（jpg、png、webp、gif）
- 检查图片大小是否超过限制（默认 10MB）

问题五: Redis 连接失败

解决方法:
- 如果不需要缓存功能，在 backend/config/index.js 中设置 redis.enabled: false
- 如需使用 Redis，检查 Redis 服务是否启动（执行 redis-cli ping，应返回 PONG）
- 检查 Redis 配置中的主机和端口是否正确
- 检查 Redis 密码是否配置正确

问题六: 数据库连接失败

解决方法:
- 检查 MySQL 服务是否启动
- 检查数据库用户名和密码是否正确
- 检查数据库 web 是否已创建
- 检查数据库表是否已导入（执行 SHOW TABLES 查看）
- 检查防火墙是否阻止了 3306 端口访问
